A test that compares two things often needs a line saying the two were
different to begin with, or it passes while comparing something with itself.
That line is an assertion and gets read as ceremony, so it is written loosely -
and a loose one is satisfied by whatever happens to make it true, which need not
be the thing it was put there for.

That record's comparison asked whether a pruning had dropped a measurement, by
comparing what it kept against the whole list it was handed. It passed at every
setting. It passed because a stand-in answered at one point however it was
sampled, so the list carried the same measurement several times over and the
pruning removed a repeat whatever it was given. The guard was protecting a set
against itself, and said the test was live.

The repair is to count the thing claimed rather than a set that contains it -
the *distinct* measurements rather than the length. Then a drop is a drop.

**The shape one step past that is the guard missing altogether.** A rule
written as "nothing is wrong" - a list of faults, empty - holds on an empty
reading, and an empty answer reads as the good outcome rather than as the
absent one. A reader pointed at the wrong directory leaves the file green while
asserting nothing. Any rule of that form wants a floor beside it, and the floor
has to name something the reading *must* find rather than count what it found -
one item per form the thing can take, so that a branch of the reader exercised
by nothing is the one the floor catches.

The same shape as [[1S]] one level down. 1S is about a criterion stated against
something the work will move, which stays true and checks nothing; this is about
a guard stated against something else that will move, which stays true and
guards nothing. Both are read as bookkeeping and both are load-bearing.
