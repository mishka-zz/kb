An inventory copied into prose is not re-derived by anything. The list of parts
is the package, the interfaces are the specification, and what works and what is
open are each re-read from where they are produced.

The measured version of that: a copied table listed names that never existed
alongside names that had been deleted, under a convention the code does not use
- while every paragraph of reasoning beside it was still true. Reasoning ages
slowly and a list ages on the next commit. The smaller form of the same fault is
a principles section that enumerates the individual checks it is about.

So the test for a line in a document like this is whether it would survive
somebody renaming a symbol. If it would not, it belongs where the symbol is.
